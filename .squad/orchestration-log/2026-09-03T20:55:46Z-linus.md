## Key Implementation Details

### Per-Dimension Tri-State Rules
- **Value Entry:** -1 if chasing (>5% above SMA50 AND >8% above SMA200); +1 if pullback ≥5% OR at SMA50 OR <5% below SMA200
- **Trend:** -1 if structural downtrend (>8% below SMA200 AND SMA50<SMA200); +1 if healthy (≥SMA200 and SMA50≥SMA200)
- **Momentum:** -1 if overbought (RSI>70 OR oscillator=STRONG_BUY); +1 if RSI≤50 AND (MACD=Buy or Stoch=Buy or oscillator∈{SELL,NEUTRAL})
- **Income:** -1 if cut/suspended OR consensus STRONG_SELL with >15% downside; +1 if yield≥2% OR payout<60%, AND consensus∈{BUY,STRONG_BUY,HOLD}
- **Calendar:** -1 if earnings≤3d OR gap-down without stabilization; +1 if earnings>14d

### Missing-Data Behavior
- Uses `score_breakdown_{dim}_invalid` flags from validator
- A dimension is "missing" only if the breakdown key was absent OR its value not in {-1,0,+1}
- Deliberate LLM 0 (valid value) does NOT set the flag and is never miscounted
- ≥3 missing dimensions → cap at WAIT with insufficient_data flag

### State Thresholds
- -5 to -3: AVOID
- -2 to -1: UNFAVORABLE
- 0 to +1: WAIT
- +2 to +3: ACCUMULATE
- +4: BUY
- +5: BUY (→ STRONG_BUY only via exceptional gate)
