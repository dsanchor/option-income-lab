## Key Design Points

- Persistence writes always merge-then-write (never blind replace).
- Read path: memory → hydrate from store → fetch live.
- `invalidate()` drops only memory; `purge()` is explicit destructive admin.
- Derived fields always recomputed after merge.

## Failure Mode: D1-D5 Rejection
